## 1. 理論的妥当性の評価

### 1.1 学習可能なIFFT（LearnableIFFT1D）

#### 理論的根拠

✅ **IFFT の線形性**
```
逆フーリエ変換 IFFT は線形変換であり、行列 W で表現可能：
y = W · x,  where W ∈ ℂ^(N×N)

PyTorch での実装:
y_base = torch.fft.ifft(x, dim=self.dim, norm='ortho')
```

✅ **学習可能な補正の追加**
```
基準変換（物理的 IFFT）に、周波数ごとの位相シフトを加算：
y = IFFT(x) ⊙ exp(i·φ[k])

ここで φ[k] ∈ ℝ^N は学習可能パラメータ、⊙ は要素積
```

✅ **複素微分の可能性**
```
PyTorch の torch.complex は自動微分をサポート：
- 複素数の勾配計算が可能
- Wirtinger微分が内部で計算される
```

#### 数学的に成立する条件

1. **複素微分可能性**
   - ✅ PyTorch が torch.complex で保証

2. **勾配の流れ**
   ```python
   # 逆伝播経路
   dL/dφ = (dL/dy) · (dy/dφ)
   
   dy/dφ = i · IFFT(x) · exp(i·φ)  # 位相微分
   
   この勾配は単位円上の操作のため、||∇φ|| ≤ 1 で抑制される
   ```

3. **数値安定性**
   - ✅ 位相補正のみ（振幅保存）により、エネルギーの爆発的増加を防止
   - ✅ 初期値を φ[k]=0（補正なし）にすることで、訓練初期は物理的IFFT と等価

#### 低ランク分解による効率化

```
完全な位相補正の場合：パラメータ数 = N
低ランク分解の場合：パラメータ数 = r（ランク）

現在の実装: r=8, N=320 → 97.5% のパラメータ削減
```

**数学的原理**:
```
φ[k] ≈ U · V^T  where U,V ∈ ℝ^(N×r)

これは k-space における位相ずれが低周波成分で支配されるという
物理的観察に基づいている（磁場不均一性は滑らかな空間変化）
```

### 1.2 分離可能処理（Separable Processing）

#### 理論的根拠

✅ **2D DFT の分離可能性**
```
数学定理: 2D DFT は x軸と y軸で独立に計算可能
DFT2D[x[m,n]] = DFT_y(DFT_x(x))

証明:
X[k1,k2] = Σ_m Σ_n x[m,n] exp(-2πi(mk1/M + nk2/N))
         = Σ_m [Σ_n x[m,n] exp(-2πink2/N)] exp(-2πimk1/M)
         = DFT_y(DFT_x(x))
```

✅ **計算量の削減**
```
2D IFFT: O(N² log N)  （2D の全点で計算）

分離型 1D IFFT:
  - kx軸: O(N log N) × N 行 = O(N² log N)
  - ky軸: O(N log N) × N 行 = O(N² log N)
  - 理論上は同じだが、メモリレイアウトの改善で実行時改善

分離処理 + UNet: O(N²) の演算を軸ごとに分散
```

✅ **物理的合理性**
```
MRI の k-space サンプリング:
- kx軸（周波数エンコード）: 通常フルサンプリング、情報量豊富
- ky軸（位相エンコード）: アンダーサンプリング対象、情報量不足

→ 軸ごとに異なる処理を施すことは物理的に合理的
```

### 1.3 極端なアンダーサンプリング（20倍）

#### 情報理論的考察

🔴 **Nyquist–Shannon定理の適用**
```
古典的サンプリング定理:
  サンプリング周波数 ≥ 2 × 最大周波数

MRI 20倍加速の場合:
  必要周波数 = 2 × 実周波数
  実サンプリング周波数 = 実周波数 / 20
  
  → 完全な情報復元は情報理論的に不可能
```

✅ **Compressed Sensing（圧縮センシング）理論**
```
仮説: 自然画像（MRI）はスパース性を持つ
     S = #{非ゼロ要素} << N （画像サイズ）

定理: スパース信号は、以下の条件で部分的なサンプルから復元可能
  1. サンプリング行列 Φ が Restricted Isometry Property (RIP) を満たす
  2. 凸最適化 L1 正則化を用いる
  3. サンプル数 ≥ O(S log(N/S))

MRI 20倍加速の例:
  脳 MRI: S (実効次元) ≈ 30-50k （うち大部分は背景）
  20倍加速でも: N/20 ≈ 1M サンプル （十分 >> O(S log(N/S))）

結論: 理論的には可能だが「診断に十分な品質」が目標
      （100% の完全復元ではなく、80-90% の品質を想定）
```

✅ **Deep Prior（ニューラルネット正則化）**
```
ニューラルネットの構造自体が正則化として機能：
- 浅いネットワーク → 高周波要素を削減 → スパース化効果
- Skip connection → 低周波情報を保存 → リカバリ効果
- Dense block → 段階的特徴抽出 → 構造化

結果: 学習済みモデル = 「脳 MRI の事前知識」として機能
```

#### 実現可能性の評価

```
20倍加速での画像品質の期待値：

診断タスク          PSNR    SSIM    診断精度
フルサンプリング    -       1.0     100%
4倍加速 (実用レベル) 35-40  0.85-90 98%+
8倍加速 (研究段階)   30-35   0.75-85 95%+
20倍加速 (挑戦的)     25-30   0.60-75 ?
```

**結論**: 理論的には可能だが、以下の条件付き：
- 「完全な復元」ではなく「診断に十分な品質」を目標
- アーチファクト（ノイズ、エイリアジング）を許容
- 臨床医による読影実験で有効性を検証必須

## 2. 実装上の重大課題

### 2.1 ユニタリ性の喪失

#### 問題の本質

✅ **物理的IFFT はユニタリ変換**
```
IFFT の正規直交特性：
|| IFFT(x) || = || x ||  （エネルギー保存）

数学的定義:
W^H · W = I  （W は IFFT 行列、H は共役転置、I は単位行列）
```

❌ **学習可能な位相補正での破壊**
```
y = IFFT(x) ⊙ exp(i·φ[k])

位相補正は単位円上の操作なので、理論上はユニタリ性を保持：
|exp(i·φ)| = 1 → || y || = || IFFT(x) || = || x ||

しかし実装上の問題:
- 浮動小数点数値誤差
- 低ランク分解によるφ[k] の近似誤差
- 結果：エネルギーが徐々に散逸
```

#### 対策と検証方法

```python
# 実装案1: エネルギー保存の監視
def check_energy_conservation(x, y):
    """
    入出力のエネルギー比を監視
    """
    energy_in = torch.norm(x)
    energy_out = torch.norm(y)
    energy_ratio = energy_out / (energy_in + 1e-8)
    
    # 警告: 比が 0.95 以下なら警告
    if energy_ratio < 0.95:
        print(f"⚠️ Energy loss: {energy_ratio:.4f}")
    
    return energy_ratio

# 訓練ループでの監視
for batch in dataloader:
    y = model(batch)
    energy_ratio = check_energy_conservation(batch, y)
    # -> TensorBoard に記録
```

```python
# 実装案2: ユニタリ制約の明示的実装
class UnitaryConstrainedLearnableIFFT1D(LearnableIFFT1D):
    """
    ユニタリ性を明示的に保証する版
    """
    def forward(self, x):
        # 基準IFFT
        y_base = torch.fft.ifft(x, dim=self.dim, norm='ortho')
        
        # 位相補正（大きさ1に正規化）
        phase = self.phase_parameter
        phase = F.normalize(phase, p=2, dim=0)  # L2 正規化
        
        correction = torch.exp(1j * phase)
        
        # 出力のエネルギーを入力と同一にする
        y = y_base * correction
        y = y * (torch.norm(x) / (torch.norm(y) + 1e-8))
        
        return y
```

### 2.2 共役対称性の破壊

#### 問題の本質

**MRI k-space の物理的制約**:
```
実信号 x(t) ∈ ℝ → k-space K(ω) は共役対称

数学的表現:
K[k] = K*[-k]  （共役対称）

これにより、復元画像は必ず実数値となる
```

❌ **完全学習可能な複素変換での問題**:
```
学習可能変換が共役対称性を保証しない場合：
y = W · x  where W ∈ ℂ^(N×N) （任意の複素行列）

結果：
1. 復元画像に虚部が残存: y = y_real + i·y_imag （y_imag ≠ 0）
2. 物理的に不自然（実信号なのに複素値）
3. 診断上の問題（虚部が診断値を歪める）
```

#### 対策1: 位相補正での自動保証

✅ **現在の実装は自動的に共役対称性を保持**:
```python
# LearnableIFFT1D での処理
y_base = torch.fft.ifft(x, dim=self.dim, norm='ortho')
# → y_base は既に実数（IFFT の性質）

correction = torch.exp(1j * self.phase)
y = y_base * correction
# → 実数 × exp(i·φ) = 複素数？

# 問題: y が複素数になってしまう！
```

⚠️ **実装上の課題**: 実装コードを確認する必要あり

#### 対策2: 明示的な共役対称性強制

```python
class ConjugateSymmetryConstrainedIFFT(LearnableIFFT1D):
    """
    共役対称性を明示的に保証する版
    """
    def forward(self, x):
        # 基準IFFT（実数出力）
        y_base = torch.fft.ifft(x, dim=self.dim, norm='ortho')
        # y_base は実数で、自動的に共役対称性を保有
        
        # 位相補正も共役対称に制約
        phase = self._get_conjugate_symmetric_phase()
        
        # 位相補正を適用
        # ただし y_base × exp(i·φ) は複素数になるため注意
        # 
        # 解決策: 位相補正の前に k-space で適用
        # y_corrected = IFFT(x ⊙ exp(i·ψ[k]))
        
        x_corrected = x * torch.exp(1j * phase.unsqueeze(-1))
        y = torch.fft.ifft(x_corrected, dim=self.dim, norm='ortho')
        
        return y
    
    def _get_conjugate_symmetric_phase(self):
        """
        共役対称な位相パラメータを生成
        ψ[-k] = -ψ[k] を満たすように
        """
        N = self.phase_parameter.size(0)
        phase_sym = torch.zeros(N, dtype=self.phase_parameter.dtype)
        
        for k in range(N // 2):
            phi_k = self.phase_parameter[k]
            phase_sym[k] = phi_k
            phase_sym[N - k - 1] = -phi_k
        
        return phase_sym
```

```python
def train_step(model, batch, optimizer):
    loss = model(batch)
    loss.backward()
    
    # 勾配ノルムの監視
    total_norm = 0
    for p in model.parameters():
        if p.grad is not None:
```

```python
# テストスクリプト
def test_gradient_stability():
    """
    勾配が爆発・消失しないことを確認
    """
    model = LearnableIFFT1D(N=320, rank=8)
    x = torch.randn(1, 16, 320, dtype=torch.complex64)
    
    # Forward pass
    y = model(x)
    
    # Backward pass
    loss = y.abs().sum()
    loss.backward()
    
    # 勾配ノルムの統計
    grad_norms = []
    for name, param in model.named_parameters():
        if param.grad is not None:
            grad_norm = param.grad.norm().item()
            grad_norms.append((name, grad_norm))
            print(f"{name}: {grad_norm:.6f}")
    
    # チェック
    max_grad = max([g[1] for g in grad_norms])
    min_grad = min([g[1] for g in grad_norms if g[1] > 0])
    
    assert 1e-8 < min_grad, "❌ Vanishing gradients"
    assert max_grad < 10, "❌ Exploding gradients"
    print("✅ Gradient stability OK")
```

```python
def test_conjugate_symmetry():
    """
    復元画像が実数かつ共役対称を保つことを確認
    """
    model = LearnableIFFT1D(N=320, rank=8)
    
    # k-space データ（共役対称）
    K_full = torch.randn(1, 16, 320, dtype=torch.complex64)
    K = K_full.clone()
    # 共役対称を強制（テスト用）
    for k in range(K.shape[-1] // 2):
        K_conj_k = K_full[:, :, -k-1].conj()
        K[:, :, k] = K_full[:, :, k]
        K[:, :, -k-1] = K_conj_k
    
    # 復元
    img = model(K)
    
    # チェック
    imag_part = img.imag.abs().max().item()
    assert imag_part < 1e-5, f"❌ Imaginary part: {imag_part}"
    print("✅ Conjugate symmetry preserved")
```

## 5. 今後の実装の指針

### 推奨事項

1. **複素行列アプローチの失敗を明示的に記載**
   - 学位論文・論文に「Initial approach (complex matrix): failed due to gradient explosion and conjugate symmetry breaking」と記載
   - 失敗から学習への進化プロセスを示すことで、研究の誠実性を示す

2. **位相補正の理論的優位性を定量的に示す**
   - Fixed IFFT vs Learnable IFFT での勾配ノルム比較グラフ
