# 学習可能な分離型IFFT を用いた fastMRI 再構成に関する研究

## 1. 研究背景

MRI（磁気共鳴画像法）は非侵襲的な医用画像診断技術として広く利用されているが、撮像時間の長さが臨床現場における大きな課題となっている。MRI はk空間（周波数領域）を1行ずつ順番に取得するため、例えば256行・TR=500msの条件では約2分の撮像時間を要する。患者の負担軽減や検査効率の向上、さらには動きによるアーチファクトの低減のため、撮像時間の短縮が強く求められている。

この問題を解決するため、k空間のアンダーサンプリングによる高速化手法が研究されてきた。アンダーサンプリングは取得する行数を削減することで撮像時間を物理的に短縮できる（例：256行→64行で4倍高速化、撮像時間2分→30秒）。しかし、単純に行数を減らすとエイリアシングが発生し、画質が大きく劣化する。このため、深層学習を用いて失われた情報を補完し、高品質な画像を再構成する技術が重要となっている。

従来の深層学習ベースの再構成手法では、2次元逆フーリエ変換（2D IFFT）を用いてk空間から画像空間への変換を一括で行っていた。しかし、以下の課題が存在する：

- **計算コストの高さ**: O(N²logN) の計算量により、高解像度画像（640×320など）の処理に時間がかかる
- **固定変換の限界**: 物理的な IFFT は固定された線形変換であり、撮像装置の特性やアーチファクトのパターンに応じた柔軟な最適化が困難
- **メモリ消費**: 2次元全体を同時に処理するため、深層ネットワークと組み合わせた際のメモリ使用量が大きく、GPUリソースを圧迫する

本研究は、これらの課題に対する新しいアプローチとして、**学習可能な分離型 IFFT** と **軸別Dense UNet** を組み合わせたアーキテクチャを提案する。現在は基礎的な実装と検証の段階にあり、今後の実験を通じて有効性を明らかにしていく計画である。

## 2. 提案手法

### 2.0 研究アプローチの進化：複素行列から物理拘束つき部分複素化へ

本研究は、最初に複素値ニューラルネットワークを用いた **完全学習可能な複素行列変換** のアプローチを検討していた。しかし、以下の重大な課題に直面し、いったん **学習可能な位相補正** に縮退した。現在はそこから一歩進め、**物理拘束つき部分複素化（partially complex with physics constraints）** に再設計している。

**初期アプローチの失敗理由**:

1. **勾配爆発**: 複素行列の完全な学習可能化により、逆伝播計算時の勾配ノルムが急速に増大。標準的な勾配クリッピングでも制御困難であり、訓練の安定性が大きく損なわれた。

2. **共役対称性の破壊**: MRI の実信号は k-空間で共役対称性（$K(k_y, k_x) = K^*(-k_y, -k_x)$）を持つ必要があるが、完全に学習可能な複素変換はこの制約を保証できず、復元画像に虚部成分が残存。これは物理的に不自然であり、診断価値を損なう。

**再設計の理論的根拠**:

従来の複素行列学習の課題を解決するため、以下の戦略に再構成：
- **物理制約の明示化**: 物理的 IFFT を基準変換として保持
- **学習対象の限定化と拡張**: 位相のみではなく、**位相 + 微小振幅補正** を学習（振幅補正は小範囲に制限）
- **共役対称性の保証機構**: 中間 k 空間に **Hermitian 投影** を入れ、実画像性を維持
- **勾配の安定化**: 補正を制約付きパラメータ化し、勾配ノルムの暴走を抑制

これにより、物理的妥当性を保ちながら、位相のみ手法より高い表現力を持つ設計を目指す。

### 2.1 アーキテクチャ概要

本手法の核心は、2次元の逆フーリエ変換を kx 軸と ky 軸の1次元変換に分離し、各軸に対して独立に処理を行う点にある。全体の処理フローは以下の通りである：

```
K-space [B, C, Ky, Kx]
  ↓ (1) Learnable IFFT (kx軸)
Hybrid space (kx変換済) [B, C, Ky, Kx]
  ↓ (2) Dense UNet (kx軸用)
  ↓ (3) Learnable IFFT (ky軸)
Image space [B, C, Ky, Kx]
  ↓ (4) Dense UNet (ky軸用)
  ↓ (5) Conv Head (coil結合)
Reconstructed Image [B, 1, H, W]
```

この設計により、2次元全体を一度に処理する従来手法と比較して、計算量とメモリ使用量を削減しつつ、各軸に特化した特徴抽出が可能となる。

### 2.2 学習可能な IFFT 層 (LearnableIFFT1D)

本研究の最も重要な技術的貢献は、**物理的な IFFT を基準として、制約付きの複素補正（位相 + 微小振幅）を加える** アプローチである。これは完全に自由な線形変換を学習する従来手法とは異なり、物理法則に基づいた制約を保ちながら柔軟性を獲得する試みである。

**設計方針**:
```python
# 基準変換: 物理的 IFFT（高速・安定）
y_base = torch.fft.ifft(x, dim=axis, norm='ortho')

# 学習可能な補正: 周波数ごとの位相 φ[k] と微小振幅 α[k]
# α は tanh で制限し、(1 + ε·tanh(α)) を掛ける（例: ε=0.1）
amp = 1.0 + eps * tanh(alpha)
phase = exp(i * scale * phi)
y = y_base * amp * phase

# 物理整合性の維持: 必要に応じて Hermitian 投影
y = hermitian_project(y)
```

**特徴**:
1. **物理的妥当性**: Hermitian 投影により共役対称性を維持し、実数信号性を担保
2. **数値安定性**: 振幅補正を小範囲に制限し、勾配爆発を抑制
3. **解釈性**: 位相と振幅の補正量を分離して可視化でき、撮像条件との対応を分析しやすい
4. **効率性**: 低ランク分解（rank=8）により、全周波数成分の自由学習と比較してパラメータ数を大幅削減
5. **拡張性**: 将来的にマスク条件付き補正（加速率依存）へ自然に拡張可能

この設計の根拠は、MRI の劣化要因が位相誤差だけでなく微小な振幅歪みも含むという観察に基づいている。完全な自由度を持つ変換よりも、物理的制約下での限定的な複素補正の方が、安定性と汎化性能の両立に有利という仮説を検証していく。

### 2.3 軸別 Dense Encoder-Decoder

各軸の変換後に適用される Dense UNet は、以下の工夫により計算効率を改善している：

**メモリ最適化**（従来の Dense UNet から改良）:
- Dense Block の層数: 4層 → **2層** に削減
- Encoder-Decoder の段数: 3段 → **2段** に削減
- Growth rate: 緻密に調整して特徴マップの爆発的増加を抑制

**構造の特徴**:
```python
# AxisDenseUNet の構成
Encoder:
  e1: DenseBlock(in, growth=16, n_layers=2) → TransitionDown
  e2: DenseBlock(base, growth=16, n_layers=2) → TransitionDown
  
Bottleneck:
  DenseBlock(base*2, growth=16, n_layers=2)
  
Decoder:
  tu2: TransitionUp → Skip Connection → DenseBlock
  tu1: TransitionUp → Skip Connection → DenseBlock
  
Output:
  Conv2d(out_ch, kernel=1)
```

- **Dense Connection**: 各層が前層すべてと接続し、段階的に特徴を拡張
- **Skip Connection**: Encoder-Decoder 間で低レベル特徴を保存
- **GroupNorm**: バッチサイズに依存しない正規化で小バッチでも安定

この設計により、元の Dense UNet の表現力を一定程度維持しつつ、限られたGPUメモリ内で動作可能となっている。ただし、層数削減による表現力の低下については今後の実験で定量的に評価する必要がある。

### 3.2 ハイパーパラメータ設定

| パラメータ | 値 | 備考 |
|-----------|---|------|
| **LearnableIFFT** |||
| IFFT補正ランク | 8 | 低ランク分解による効率化 |
| 初期位相 | 0 | 学習初期は物理IFFTと等価 |
| 振幅補正係数 ε | 0.1 | 振幅補正を ±10% に制限 |

| スケール | 1.0 | 学習可能（勾配を通す） |
| **Dense UNet** |||

これらの値は予備実験と計算資源の制約から暫定的に決定したものであり、今後のグリッドサーチやベイズ最適化により調整する予定である。

### 3.3 複素数処理の実装

MRI の k-space データは複素数であるが、PyTorch の Conv2d は実数テンソルを前提としている。このギャップを埋めるため、以下の変換を実装：

```python
def complex_to_2ch(x: complex[B,C,H,W]) -> real[B,2C,H,W]:
    """複素数を実部・虚部の2チャネルに分離"""
    return torch.cat([x.real, x.imag], dim=1)

def ch2_to_complex(x: real[B,2C,H,W]) -> complex[B,C,H,W]:
    """2チャネルを複素数に再結合"""
    c = x.size(1) // 2
    return torch.complex(x[:, :c], x[:, c:])
```

この設計により、既存の畳み込み層アーキテクチャを変更せずに複素数データを扱える。ただし、complex-valued neural network の理論的優位性については今後の比較研究が必要である。

## 4. 期待される効果と現状の課題

### 4.1 計算効率の向上（理論値）

**理論的な計算量削減**:
- 2D IFFT: O(N²logN) → 2回の 1D IFFT: O(2N²logN/2)
- Dense Block の削減: パラメータ数 約40%削減

**期待される実行時間**（仮説）:
- 推論: 従来手法の **60-70%** の時間で実行
- 訓練: バッチサイズを **1.5-2倍** に増加可能

⚠️ **現状**: 上記は理論値であり、実測による検証が必要。特にPyTorchのFFT実装の最適化度合いや、GPU転送のオーバーヘッドを考慮した実時間評価が今後の課題。

### 4.2 撮像条件への適応性（仮説）

**学習可能な制約付き複素補正（位相+微小振幅）の期待効果**:
- **装置間差異の吸収**: 異なるMRI装置で撮像されたデータへの適応
- **アーチファクト補正**: モーションアーチファクトや金属アーチファクトへの頑健性
- **サンプリングパターン最適化**: k空間のアンダーサンプリングパターンごとに最適な変換を学習

⚠️ **現状**: これらは理論的な仮説であり、実データでの検証が不可欠。特に以下の実験が必要：
- アブレーション: 学習可能IFFT（位相のみ/位相+振幅） vs 固定IFFT の定量比較
- 異なる加速率（4倍、8倍）での性能評価
- クロスドメイン評価（訓練データと異なる装置・部位でのテスト）

### 4.3 物理的解釈性（利点）

**既存手法との比較**:

| 手法 | 解釈性 | 数値安定性 | 汎化性 |
|------|--------|----------|--------|
| 完全学習可能な変換 | 低 | 不安定 | 未知 |
| 固定IFFT | 高 | 安定 | 限定的 |
| **本手法（IFFT+制約付き複素補正）** | **中〜高** | **安定** | **検証予定** |

**利点**:
- 学習された位相 `φ[k]` と振幅補正 `α[k]` を可視化・分析可能
- 物理的 IFFT がベースなので、学習失敗時も最低限の品質を保証
- Hermitian 投影により共役対称性を保ち、実数画像の出力を保証しやすい

### 4.4 現時点での制限事項

本研究は現在、以下の段階にある：

1. **実装段階**: モデルアーキテクチャの実装完了
2. **予備実験**: 小規模データでの動作確認中
3. **本格評価**: fastMRI データセットでの大規模実験はこれから

**認識している課題**:
- 層数削減による表現力の低下の程度が未検証
- 学習可能IFFT の実効性が未確認（固定IFFTと差が出るか？）
- メモリ削減の実測値が理論値と一致するか不明
- 最適なハイパーパラメータ（rank, growth rate等）が未探索

### 5.0 改訂方針（物理拘束つき部分複素化）

本研究は、以降の評価軸を「位相のみ」から **制約付き複素補正（位相 + 微小振幅）** へ移す。実装・評価は次の4ステップで実施する。

| Step | 期間 | 実施内容 | 完了条件 |
|------|------|----------|----------|
| **S1: 実装更新** | 1-2週 | LearnableIFFT に振幅補正パラメータと Hermitian 投影を追加 | 学習が発散せず 1 epoch 完走 |
| **S2: 最小比較** | 2-3週 | 固定IFFT / 位相のみ / 位相+振幅 の3条件比較 | PSNR, SSIM, NMSE を取得 |
| **S3: 安定性検証** | 3-4週 | 勾配ノルム・虚部残差・共役対称性違反率を計測 | 各指標の分布図を作成 |

- 追加コスト（時間・メモリ）が実用範囲（+20%以内）

### 5.0.1 S1 実装更新の詳細タスク（最小改造版）

**対象ファイル（現行コードベース）**:
- `mri_strip_reconst/models/stripes_separable_ifft.py`
- `mri_strip_reconst/scripts/train_separable_ifft.py`
- `mri_strip_reconst/scripts/debug_performance.py`
- `mri_strip_reconst/scripts/debug_val_ssim_drop.py`

**実装仕様（LearnableIFFT1D）**:

1. **パラメータ拡張**（`__init__`）
  - `phase`（既存）に加え `alpha`（振幅補正）を追加
  - `amp_eps`（既定値 0.1）を導入し振幅補正上限を制御
  - `use_hermitian`（既定値 True）を導入

2. **順伝播更新**（`forward()`）
  - 基準変換: `y0 = ifft(x)`
  - 制約付き補正:
    $$
    A(k)=1+\varepsilon\tanh(\alpha_k),\quad
    P(k)=\exp\left(i\,s\,\phi_k\right),\quad
    y=y_0\cdot A\cdot P
    $$
  - `A(k)` は $[1-\varepsilon,1+\varepsilon]$ に収まるように実装

3. **Hermitian 投影の追加**
  - `hermitian_project()` を追加し、必要段（少なくとも `ky` IFFT 後）で適用
  - 目的: 実画像性と共役対称性を明示的に保持

4. **診断値のロギング追加**
  - `phase_norm = ||phase||_2`
  - `alpha_norm = ||alpha||_2`
  - `imag_energy = mean(|Im(y)|)`
  - `symmetry_error = mean(|K - conj(flip(K))|)`

5. **学習スクリプト引数追加**（`train_separable_ifft.py`）
  - `--amp-eps`（float, default 0.1）
  - `--use-hermitian` / `--no-hermitian`
  - `--lambda-phys`（物理整合損失重み, default 0.01）

**S1 完了判定（Done条件）**:
- 1 epoch で loss が `NaN/Inf` にならない
- `imag_energy` が baseline（位相のみ）と同等以下
- `phase_norm` と `alpha_norm` が単調発散しない
- 既存の中間可視化スクリプトがエラーなく実行可能

### 5.0.2 S2〜S4 の評価プロトコル（固定）

### 5.0.4 データサイズ不一致への対処計画（必須前処理）

実データ全件スキャンの結果、k-space 形状は単一ではなく、`ky`・`kx`・coil 数が混在している。
このままではバッチ学習が成立しないため、以下を **学習開始前の必須前処理** とする。

**観測された不一致（要点）**:
- `ky`: 512 / 640 / 768 の混在
- `kx`: 213〜416 の範囲で混在
- coil 数: 4〜20 の混在

**統一ルール（採用案）**:
1. **空間サイズ統一**
  - k-space を中心基準で `ky=640, kx=320` に統一
  - `ky,kx` が大きい場合は center-crop、小さい場合は zero-pad
2. **coil 数統一**
  - coil compression（SVD）で固定本数（例: 8 または 12）に圧縮
  - 圧縮設定は全 split で固定し、実験間で変更しない
3. **例外データ処理**
  - k-space 欠損・破損ファイルは除外リスト化
  - 除外理由をログとして保存（再現性のため）

**品質保証チェック（前処理後）**:
- 全サンプルでテンソル形状が一致すること
- DataLoader でバッチ化エラーが 0 件であること
- 前処理前後で強度統計（平均・分散）が極端に崩れないこと

**Done条件**:
- 前処理済み train/val/test の shape 分布が各 split 内で 1 種類に収束

- 前処理設定（crop/pad/coil圧縮）が設定ファイルに固定化されている

### 5.3 長期展望（6ヶ月以降）

**拡張研究の方向性**:

1. **3次元MRIへの拡張**
   - 3軸分離処理（kx, ky, kz）
   - ボリュームデータの効率的処理
   - 計算量: O(N³logN) → O(3N³logN/3) の理論的削減

2. **マルチモーダル・マルチコントラスト**
   - T1, T2, FLAIR 等の複数コントラストの同時再構成
   - コントラスト間の相互情報を活用
   - Shared Encoder による効率化

3. **不確実性推定の組み込み**
   ```python
   # 将来的な拡張案
   class UncertaintyAwareIFFT(LearnableIFFT1D):
       def forward(self, x):
           mean = super().forward(x)
           uncertainty = self.estimate_uncertainty(x)
           return mean, uncertainty
   ```
   - 再構成の信頼度を定量化
   - 診断支援における意思決定の補助

4. **リアルタイム処理への最適化**
   - TensorRT, ONNX への変換
   - 量子化（INT8, FP16）の適用
   - 目標: 推論時間 **100ms以下**（臨床応用の閾値）

5. **異なる加速率への適応**
   - 単一モデルで 2倍〜16倍の加速率に対応
   - Dynamic network (input-dependent routing) の検討

6. **臨床データでの検証**
   - 放射線科医による読影実験
   - 診断精度への影響評価
   - 実臨床ワークフローへの統合可能性

### 5.4 技術的挑戦と対策

**予想される困難と対応策**:

| 課題 | 対応策 |
|------|--------|
| **学習の不安定性** | ・段階的学習（固定IFFT→学習可能に移行）<br>・位相補正のスケール調整<br>・Gradient clipping の導入 |
